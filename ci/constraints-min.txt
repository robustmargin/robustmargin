# Dependency floors, pinned exactly, for the minimum-versions CI job. The floors in
# pyproject.toml stay loose so the package never forces a numpy or scipy version on a user's
# environment, and this job proves the package works at them.
#
# This file repeats the floors declared in pyproject.toml's `dependencies`. If these three
# numbers disagree with pyproject.toml, this file is the one that is wrong.
#
# PYTHON 3.11 ONLY in CI. This set is installable on 3.11 and 3.12 but not on 3.13, and that is a
# property of the published wheels, not a gap to be fixed:
#   numpy 1.26.0       cp312 wheel, no cp313 wheel; declares python_requires <3.13
#   scipy 1.12.0       cp312 wheel, no cp313 wheel
#   statsmodels 0.14.0 cp312 wheel, no cp313 wheel
# A newer interpreter only ever resolves to newer dependencies, so testing the floor on 3.11
# is the whole guarantee. Do not "fix" the CI matrix into a full cross product.
numpy==1.26.0
# 1.12.0 is the first scipy with `scipy.optimize.isotonic_regression` (1.11.4 has none), which
# the isotonic fit uses.
scipy==1.12.0
statsmodels==0.14.0
